📖 What Is Punctum?

Punctum is a typeface, which is simply a font — the set of letter shapes your computer uses to display text. What makes Punctum different is that it is drawn entirely out of dots. Every letter is built on a grid that is 5 dots wide and 7 dots tall, the same way old computer screens and dot-matrix printers used to build letters.

Because Punctum is a variable font, it does not come as a dozen separate files. Instead, it comes as one file that contains a whole range of styles inside it. You can slide between them with two simple controls:

  • Dot size — makes each dot in the letter bigger or smaller, so the text can look light and airy or bold and chunky.
  • Dot shape — changes the outline of each dot, so the letters can look sharp and technical or soft and rounded.

You do not need any design degree or coding skill to use it. If you can pick a font in a dropdown menu, you can use Punctum.

🚀 Getting Started on Windows

This is a font, not a program. You do not need to install anything complicated, and you do not need to run a setup wizard. You only need to download the font file and add it to Windows.

⬇️ Get Punctum from the Releases Page

Download step: Visit this link to download the application.

  1. Click the download button above. Your browser will open the Punctum releases page.
  2. On that page, find the newest release at the top of the list. It is usually marked as "Latest".
  3. Click the font file in that release to save it to your computer. By default it will land in your Downloads folder.
  4. Open the Downloads folder. You can get there quickly by pressing the Windows key, typing Downloads, and pressing Enter.
  5. Right-click the font file and choose Install (or Install for all users if you want everyone on the computer to be able to use it).
  6. Wait a few seconds. Windows will show a short confirmation when the font is ready.
  7. Close and reopen any program that was already open — Word, PowerPoint, Photoshop, or anything else. New fonts only appear in apps after they restart.
  8. Open the font menu in that program and look for Punctum. Select it and start typing.

If the file does not open with a right-click

Some computers are set up so that double-clicking a font file opens a small preview window instead of installing it. If that happens, look at the top of the preview window for a button labelled Install and click it. The result is exactly the same.

Using the variable settings

Variable fonts need a program that supports variable settings to show their full range. Recent versions of Adobe apps, Figma, and many modern design tools have a small panel labelled "Variable" or "Variable Font" next to the font name. If you see it, you will find two sliders there — one for dot size and one for dot shape. If your program does not show that panel, the font will still work: it simply appears at its default setting.

💡 Tips for Getting the Best Result

  • Use it large. Dot-matrix faces shine at bigger sizes, where each dot is clearly visible. Use Punctum for headlines, covers, and titles rather than long paragraphs.
  • Start at the default. Install the font first, see how it looks, and only then start moving the dot size and dot shape sliders. It is much easier to judge the changes once you know the baseline.
  • Try small dot sizes for a delicate look. Shrinking the dots makes the lettering feel lighter and more elegant, which works well on light backgrounds.
  • Try round dots for a friendly look. Changing the dot shape softens the whole alphabet and makes it feel less mechanical.
  • Check the spacing. Very large or very small dot settings can change how tightly letters sit together. If something looks crowded, add a little letter spacing in your program's text settings.
  • Keep a copy of the file. Save the downloaded font somewhere safe, such as a fonts folder in your documents. If you ever move to a new computer, you can install it again in seconds.

❓ Common Questions

Is it really free?

Yes. Punctum is released under an open font licence, which means you can use it in personal and commercial work at no cost. That is why it is hosted publicly on GitHub.

Do I have to be a programmer to use GitHub?

No. You only need to open the releases page, click the file, and install it the same way you would install any font. You never need to type commands or use a terminal.

I installed it but my program cannot find it.

Restart the program completely — closing the window is not always enough, so quit it from the taskbar and open it again. If it still does not appear, restart your computer, which forces Windows to refresh the list of installed fonts.

Can I use it on a Mac or a phone?

The download steps above are written for Windows. The font file itself is a standard format that works on other systems too, but the menu names and install steps will look different.

Something is not working.

Go back to the releases page and check that you picked the newest release and downloaded the font file rather than a source code archive. If the problem continues, you can open an issue on the repository and describe what you see.
